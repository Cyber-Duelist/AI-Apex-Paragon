# SentinelAlpha — AI Hedge Fund Intelligence Platform

AI-powered alternative data intelligence platform that analyzes SEC filings, earnings call transcripts, and market signals to generate actionable alpha conviction scores.

## Features
- **SEC Filing Intelligence** — Automated 10-K/10-Q risk factor extraction and delta analysis
- **Earnings Call Analyzer** — Management sentiment scoring, hedge word detection, forward guidance extraction
- **Alpha Conviction Engine** — Multi-signal aggregation into a single bullish/bearish conviction score

## Tech Stack
Python · FastAPI · Streamlit · Groq (Llama 3) · SEC EDGAR API · Plotly
