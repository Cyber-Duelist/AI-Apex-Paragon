# Document Attention Classifier

## Goal

This mini project predicts whether a document needs human attention based on document metadata.

It is a small end-to-end machine learning workflow covering:

- data loading
- feature selection
- target creation
- preprocessing
- model training
- model evaluation
- model saving
- loading the saved model for inference
